PlanX CAD - QGIS Smoke Test Checklist

Use this in a real QGIS session after plugin updates.

1. Startup

  1. Open dock and verify no load error.
  2. Run Preflight, Health, and Key Audit.
  3. Confirm active vector layer + editable state.

2. Core Tool Pass

  • Drawing: line, polyline, rectangle, circle
  • Editing: trim, extend, offset, fillet, chamfer
  • Modify: break (BR), lengthen (LEN), align (AL), stretch (S), explode (X)
  • Transform: move, rotate, mirror
  • Measure: distance + dimension
  • Urban: road or junction basic path

3. UX Pass

  • Search + Command Palette launch commands correctly.
  • Recent/Favorites rows update as expected.
  • Diagnostics report and usage stats open without error.

4. Failure Reporting

If any step fails, open Issue Template from plugin menu and attach diagnostics text.
