PlanX CAD - Komut Kullanim Rehberi

Bu dokuman QGIS icinde hizli ve hatasiz CAD calismasi icin komut akislari ve incelikleri verir.

1. Cizim Komutlari

Line / Polyline / Arc / Circle
  • Komutu secin, mümkünse snapping acik olsun.
  • Ilk noktayi net secin; ikinci noktada snap ile topolojik temiz bitis alin.
  • Uzun seri cizimde Polyline tercih ederek tek feature uretin.

2. Duzenleme Komutlari

Trim / Extend / Fillet
  • Aktif katmanin edit modda oldugundan emin olun.
  • Trim-Extend zincirlerinde once ana referans cizgiyi, sonra hedefi secin.
  • Fillet'te kucuk yaricaplar, dar acilarda daha kararlidir.
Hatch / Construction
  • Hatch icin kapali poligon geometri kullanin.
  • Construction modlari:
    • Infinite: genel aks ve grid referansi
    • Ray: tek yon uzama gereken yol/sinir projeksiyonu
    • Segment: kontrollu gecici referans

3. Donusum Komutlari

Move / Copy / Rotate / Scale / Mirror / Array
  • Base point secimi sonucu dogrudan etkiler; snap ile secin.
  • Array ile tek tek kopya yerine parametrik duzen kurun.
  • Mirror'da referans ekseni dogru secilmezse geometri terse duser.

4. Olcum ve Etiketleme

Measure / Dimension
  • Dimension kalici katman olusturur; proje tesliminde izlenebilirlik saglar.
  • Secime dayali olcumlerde coklu secim oncesi filtre uygulamak daha guvenli olur.

5. Uretkenlik Ipuclari

  • Ctrl+Shift+S: arama kutusuna odaklan, komutu yazarak ac.
  • Ctrl+Shift+Space: son araci tekrar et.
  • Dock'taki Recent satiri ile sik komutlara hizli don.
  • Dock'ta Docs ve Keys butonlari ile yardim ekranlarina aninda gec.
