PlanX CAD - Command Reference

Use this reference to build accurate, topology-safe CAD workflows in QGIS.

1. Drawing Commands

Line / Polyline / Arc / Circle
  • Activate command, keep snapping enabled for topology-safe output.
  • Lock the first point carefully; use snap on second point for clean endpoint closure.
  • Use Polyline for long chains to keep a single continuous feature.
Precision Point Input
  • x,y: absolute point in the map canvas CRS.
  • @dx,dy: relative Cartesian offset in metres.
  • @distance<angle: relative polar point in metres and degrees.
  • distance: distance in metres along the current cursor bearing.
  • Type a number, minus sign, or @ directly on the canvas, or focus the command line with Ctrl+Shift+S.

Point input works with Line, Polyline, Rectangle, Circle, Polygon, Arc, Move, and Copy. Rotate accepts signed degrees; Scale accepts a positive factor. Metric input remains metre-accurate in geographic projects.

Precision Drafting: OSNAP, Tracking & Dynamic Input (v1.28.0)
  • F3 or OSNAP: Object Snap with AutoCAD-standard typed glyphs (Box=Endpoint, Triangle=Midpoint, Circle=Centre, Diamond=Quadrant, Cross=Vertex, X=Intersection, Inverted Triangle=Perpendicular, Tangent, Nearest, Extension).
  • F8 or ORTHO: Orthogonal drafting lock (0 deg, 90 deg, 180 deg, 270 deg) with live dashed alignment ray.
  • F10 or POLAR: Polar angle tracking (15 deg, 30 deg, 45 deg, 90 deg rays) with angle lock readouts.
  • Object Snap Tracking: Hover over a snapped point to acquire it; alignment rays along X and Y axes take precedence over polar angles.
  • F12 or DYN: Floating cursor Heads-Up Display (HUD) showing live length, angle, and delta-x/delta-y metrics.

2. Editing Commands

Trim / Extend / Fillet
  • Ensure target layer is editable before operation.
  • In Trim/Extend sequences, pick reference boundary first, then target geometry.
  • For tight intersections, smaller fillet radius is usually more stable.
Chamfer CHA
  • Enter both cutback distances first; tick Use the first distance for both lines for a symmetric cut.
  • Pick the first line, then the second; the hover preview shows the cut before you commit.
  • Both lines are trimmed to the corner and the chamfer segment is added as a new feature.
  • A distance longer than the retained leg is rejected rather than corrupting the source line.
Break BR
  • Pick the line, click the first break point, then click a second point to remove the span between them.
  • Press Enter or right-click after the first point to break there with no gap.
  • The picked feature keeps the first part; the remainder is added as a new feature with the same attributes.
  • A break on an endpoint is rejected: pick a point between the two ends.
Lengthen LEN
  • Click the line near the end you want to change; that end is the one that moves.
  • Delta adds or removes length (negative shortens), Percent scales the current length, Total sets an absolute length.
  • Values are metres and stay metre-accurate in geographic projects.
Align AL
  • Optionally tick Scale to match the destination distance before starting.
  • Pick the feature, then source point 1, destination point 1, source point 2, destination point 2.
  • Press Enter after the first pair to move without rotating.
Stretch S
  • Click two opposite corners to define a crossing window, then pick the base and target points.
  • Only the vertices inside the window move; every editable layer crossing the window is stretched in one step.
  • Polygon rings stay closed, so areas remain valid after the stretch.
Explode X
  • Parts turns a multipart feature into single-part features on the same layer.
  • Segments turns a line, or a polygon boundary, into two-point segments.
  • Polygon segments are written to a managed planx_explode line layer, since a polygon layer cannot hold them.
  • Untick Remove the source feature to keep the original alongside the pieces.
Hatch / Construction
  • Hatch requires closed polygon geometry for reliable clipping.
  • Construction modes:
    • Infinite: axis and grid references
    • Ray: one-direction projection
    • Segment: bounded temporary reference

3. Transform Commands

Move / Copy / Rotate / Scale / Mirror / Array
  • Base point quality directly affects geometric accuracy.
  • Use Array for repetitive layouts instead of manual copies.
  • Validate mirror axis before confirming to avoid flipped planning layouts.

4. Measurement and Annotation

Measure / Dimension
  • Dimension creates persistent features, improving auditability in deliverables.
  • For selection-based measurement, pre-filter candidates to avoid accidental totals.

5. Urban Workflow Notes

Urban Commands
  • Road/Junction/Block Chamfer tools should start from a clean centerline and editable target layer.
  • Run the layer check (dock ⋯ menu) before generating complex road platform geometry.
Street and parcel design

These tools read any vector layer and write to their own planx_* polygon layers, so the source data is never changed. Their settings sit on the dock's active-command card; with the dock hidden a short form opens instead. Lengths are metres in a local metric CRS.

  • ENV Buildable Envelope: click a parcel near its front edge. The nearest edge is the front, edges parallel to it in the far half are rear, the rest are sides. Corner parcel adds the neighbouring edge nearest the click as a second front. The envelope is every point that keeps each setback from its edge, so concave parcels are handled exactly. Fields: parcel and envelope area, buildable share, max footprint under Max coverage.
  • SIGHT Sight Triangle: pick the curb line on each arm of the corner. The legs start where the curbs meet, or where their extensions meet at a rounded corner, and run toward the points you clicked.
  • PARK Parking Layout: pick the curb line, move to the side for the stalls (a preview follows), click. Angles 90°, 60°, 45°, 30° or parallel; stalls fill each straight segment, and at a bend toward the stalls the clashing corner stalls are left out.
  • RB Roundabout: click the junction centre (snapping helps). Parts: circulatory carriageway, optional truck apron, central island. If the active layer is a line layer, every line crossing the outer kerb gets a triangular splitter island on its approach.
  • CUL Turning Head: pick a road centreline near the end; a turning circle is centred on that end and joined to the carriageway by straight tapers.

6. Productivity Workflow

  • Ctrl+Shift+S: focus search and launch by typing command name.
  • Ctrl+Shift+Space: repeat last tool instantly.
  • Use the Quick strip (pinned and recent tools) and the prompt on the active-command card.
  • Set tool values such as fillet radius or offset distance on the active-command card instead of a dialog.
  • Use ? on the active-command card to jump to that tool's section.
  • Open the dock's ⋯ menu for the command reference, shortcut guide, health check, diagnostics and usage statistics.
