PlanX CAD Toolset

AutoCAD-style drafting workbench inside QGIS • v1.27.0 • 39 tools

1. Overview

PlanX CAD Toolset is a QGIS plugin delivering an AutoCAD-style drafting workbench with 39 tools across six categories: drawing, editing, construction, transform, measurement, and urban planning. Every tool is accessible through an AutoCAD-style command line with muscle-memory aliases (L, TR, F, CO, etc.), an empty-Enter-repeat-last convention, Up/Down history recall, and a searchable command palette. The plugin has zero external dependencies and supports QGIS 3.28 through 4.x on both PyQt5 and PyQt6.

3. Drawing Tools

6 Tools with Precision Input

  • Line L: 2-click segment, auto-finish.
  • Polyline PL: N-click chain; Enter/Right-click to finish; Backspace to undo last vertex.
  • Rectangle REC: 2 opposite corners; metric-safe in geographic CRS.
  • Polygon POL: Dialog for N sides (3–100), then centre + radius.
  • Circle C: Centre + radius point; 64 segments; metric-safe.
  • Arc A: 3-point arc (start, intermediate, end); circumcircle method.

All drawing tools support native QGIS snapping, precision point input, Backspace undo, Enter finish, and Escape cancel.

4. Editing and Construction Tools

20 Tools with Live Preview

Trim TR: Pick cutting boundary, then the target line side to remove.

Extend EX: Pick boundary, then the line to extend along its terminal segment direction.

Fillet F: Enter radius, pick two lines; live hover preview; auto-trims both lines to the tangent arc.

Chamfer CHA: Enter d1/d2 with "equal" checkbox; live hover preview; rejects cutbacks longer than the retained leg.

Break BR: Pick line, click two break points or Enter after one for break-at-point; first part stays on original, remainder added as new feature.

Lengthen LEN: Pick line near end to change; Delta/Percent/Total modes; extension follows terminal segment direction.

Align AL: Pick feature, source1, destination1, source2, destination2; Enter after first pair = translate only; optional scaling by pair length ratio.

Stretch S: Crossing window defines vertices to move; operates across all editable layers at once; polygon rings stay closed.

Explode X: Parts (multipart to single-part) or Segments (line/polygon to two-point segments); optional source removal.

Buffer B: Dialog for distance/join-style/segments; writes to managed planx_buffer layer.

Hatch H: Pick polygon; pattern (parallel/cross/diagonal), spacing, angle, colour; clipped to polygon; 20,000 line limit.

Construction XL/RAY/SEG: Infinite, ray, or segment modes on managed planx_construction layer; dashed cyan style.

Divide DIV: Split line into segments or create points; writes to planx_divisions layer.

Multi-Offset MO: Comma-separated distances; left/right/both/clicked-side modes; batched undo.

Join J: Pick multiple lines, right-click/Enter to join; dialog tolerance; replaces first feature, deletes originals.

Vertex Edit VE: Drag box handles to move, click line to insert, right-click handle to delete; multipart-safe.

Offset O: Enter distance, click side for preview; left/right/both options; metric-safe.

5. Transform Tools

6 Tools with Affine Precision

Move M / Copy CO: Base point + target; precision input support (relative, polar, direct distance).

Rotate RO: Signed degrees or point target; Ctrl for 90-degree snap.

Scale SC: Factor or point target.

Mirror MI: Axis defined by two points; validates axis before confirming.

Array AR: Rectangular (rows x cols with independent dx/dy) or polar (count x sweep angle with live preview); 10,000 copy limit.

All transforms are multipart, curve, and Z/M-safe via QTransform-based affine operations.

6. Measurement and Annotation

5 Tools

Measure Distance: Click-click with live running total; geodesic if canvas is geographic.

Measure Area: Click vertices, auto-closes polygon; shows area + perimeter.

Measure Selected: Reports length or area of a selected feature via dialog.

Dimension DIM: Creates persistent linear dimension features on planx_dimensions layer with distance_m, label, and from/to coordinate fields; auto-enables labels.

7. Urban Planning Tools

Road Platform Generator ROAD

Dialog controls: road type (Vehicular/Pedestrian/Bicycle/Collector/Arterial), direction, lane count (1–8), lane width (2–10 m), median width (0–20 m), sidewalks (0–10 m each side). Live total width readout. Generates centerline, lane lines, median, and sidewalk edges on planx_road_platform layer.

Junction Solver JUNCTION

Dialog: impact radius (3–100 m), corner solution (Chamfer/Fillet), chamfer distance / fillet radius, island type (None/Round/Teardrop). Schematic preview. Click junction centre; solves half-edge curb intersections; trims road platform components at tangent points; creates traffic islands on planx_junction_islands layer.

Block Chamfer BLOCK

One-click corner filleting for block/parcel geometry. Curved (tangent fillet) or Straight chamfer; configurable distance/radius and tolerance. Finds two intersecting lines near the click, trims both, adds chamfer or arc. Automatic short remnant cleanup.

8. Precision Point Input

Four Input Formats, Metre-Accurate in All CRS

  • x,y — absolute point in canvas CRS.
  • @dx,dy — relative Cartesian offset in metres.
  • @distance<angle — relative polar in metres and degrees.
  • distance — direct distance along cursor bearing.

Type a number, minus sign, or @ directly on the canvas, or focus the command line with Ctrl+Shift+S. All relative/polar/direct-distance values are resolved through a local UTM or azimuthal equidistant work CRS, ensuring metre-accuracy in geographic projects. Supported by Line, Polyline, Rectangle, Circle, Polygon, Arc, Move, Copy, Rotate (signed degrees), and Scale (positive factor).

9. Command Line

AutoCAD-Style Command Interface

The dock includes a command line with: muscle-memory aliases (65 entries mapping L, TR, CO, etc. to tools), full autocomplete by alias, tool key, and fuzzy name match, 50-entry history ring with consecutive duplicate skipping, empty-Enter to repeat the last tool, and session persistence via QSettings for recent tools and pinned favourites. Press Ctrl+Shift+Space to repeat the last tool instantly. Press Ctrl+Shift+S to focus the command line.

10. Workflow Guide

  1. Open the PlanX CAD dock from the toolbar icon. The dock shows collapsible tool groups, a command line, recent tools, and quick-action buttons.
  2. Ensure the target layer is editable. The dock's layer state indicator shows the active layer name and edit status.
  3. Choose a tool by clicking its icon, typing its alias in the command line, or using a keyboard shortcut (Ctrl+Shift+Letter for most tools).
  4. For drawing tools: keep snapping enabled. Use precision input for exact placement. Backspace to undo the last vertex, Enter to finish, Escape to cancel.
  5. For editing tools: pick the reference geometry first, then the target. Tools like Trim, Extend, Fillet, and Chamfer exclude self-pick.
  6. Use Ctrl+Shift+Space to repeat the last tool. Pin frequently used tools via the "Pin" button for one-click access.
  7. Use the Docs button for in-context help, Keys for the shortcut reference, and Diag / Stats for operational diagnostics.

11. Technical Notes

  • CRS safety: All distance-based operations use a local UTM or azimuthal equidistant work CRS. Distances stay metre-accurate in geographic projects.
  • Edit session safety: Tools distinguish between plugin-owned and pre-existing edit sessions. Multi-step edits use beginEditCommand()/endEditCommand() with full rollback on failure.
  • Managed output layers: Eight helper layers are auto-created: planx_road_platform, planx_junction_islands, planx_buffer, planx_hatch, planx_construction, planx_dimensions, planx_explode, and planx_divisions.
  • Pick aperture: 10-pixel tolerance enforced on both bounding box and real geometry distance.
  • Self-pick exclusion: Two-step tools exclude the first picked feature from the second search.
  • Accessibility: Every button has accessibleName and accessibleDescription; all tool buttons use TabFocus policy.
  • QGIS compatibility: 3.28 LTR through 4.x. PyQt5 and PyQt6 verified. Zero external dependencies.
